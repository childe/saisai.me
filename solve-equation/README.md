# 解方程学习

一元一次方程分步练习，纯静态页面，无外部依赖。

## 模式

- **自己做**：每一步从 3–4 个选项里选做法（如「两边减 2x」），选错会说明原因；最后自己填 x 的值，支持整数、负数和分数（`7/2`）。可以用「💡 提示」或切到讲解。
- **看讲解**：点「下一步」、点算式或按空格，逐步演示，每一步配一句说明。动画进行中再点一下会直接跳到这一步的结尾。

每题最后把答案代回原方程验算。

## 难度

| 难度 | 题型 |
|---|---|
| 1 入门 | `x + 5 = 12`、`x − 3 = 7`、`3x = 15` |
| 2 简单 | `3x − 4 = 11`、`20 − 2x = 8`、`15 = 3x + 6` |
| 3 中等 | `ax + b = cx + d`，答案可能是负数 |
| 4 较难 | 带括号（括号前可以是负数），答案可能是分数 |
| 5 挑战 | 带分母，两个分母时乘最小公倍数 |

自己做模式下连续 3 题一次做对自动升一级；连续 2 题错 2 次以上会建议降一级。难度和模式记在浏览器里。

## 代码

- `lib/equation.js`：方程模型、解题步骤、练习选项、验算（纯函数）
- `lib/generate.js`：五个难度的出题
- `lib/frac.js`：分数运算和答案解析
- `lib/progress.js`：自动升降级
- `lib/render.js`：记号转 HTML
- `app.js`：页面交互和动画

测试：`node --test solve-equation/test/*.test.js`
