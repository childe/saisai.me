# SaiSai.me

一个有趣的互动工具集合。

## 项目列表

### 📐 [坐标绘图器](x-y-line/coordinate-plotter.html) (x-y-line)
在坐标系中绘制直线。输入两个点的坐标，可视化显示直线。

### 🌀 [迷宫生成器](maze-gen/maze.html) (maze-gen)
随机生成不同大小的迷宫。

### 🎮 [跳一跳游戏](tiao-yi-tiao/game.html) (tiao-yi-tiao)
3D跳一跳游戏。控制主角在方块间跳跃，挑战高分。

### 🎧 [英语听力 · 一年级上册](english-audio/index.html) (english-audio)
《英语（一年级上册）》教材配套音频。按单元收听，支持慢速跟读与单曲循环。

### 🔤 [学拼音](pinyin/index.html) (pinyin)
声母韵母的四声跟练。拼音表试听、听音选形的选择题，以及带声调曲线对比的跟读打分。
