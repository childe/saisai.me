3D 迷宫：用本地 three.js 渲染的立体迷宫，与 2D 迷宫生成器同 seed 同图。

电脑用 WASD / 方向键走路、拖动鼠标转视角；触屏左边拖动走路、右边拖动转视角、双指缩放。

四种主题（花园、砖墙、积木、城堡）各有一套墙面、地板与天空。迷宫外围有配套地面，远处渐隐到雾色；视野外格子用主题雾色。

终点上方有一根金色光柱和上升的闪光；光柱被墙挡住或不在画面里时，画面边缘会出现指向终点的箭头和剩余格数。走出迷宫时会飘下彩带（系统开启「减少动态效果」时不播放）。

小地图在两种视角都显示：浅色是当前视野，暗一档是走过、看过的地方，深灰是还没去过的地方，棕色圆点是脚印（越早越淡）。舞台左上角的信息栏显示用时和星星数。第一次走动开始计时，每个尺寸记一个最佳成绩（开着「显示道路」走的那局不计入）。迷宫里藏着几颗星星，走过去就能收集，小地图上只标出已经探索到的星星。「声音」按钮同时开关音效和安卓手机的震动。
