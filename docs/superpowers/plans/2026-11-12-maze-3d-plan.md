### 墙段 `wallSegments(connections)`

返回 `Array<{ x, z, along, cells }>`：`along: 'x'` 表示墙沿 x 方向延伸（分隔南北），`'z'` 表示沿 z 延伸（分隔东西）；`cells` 是它紧邻的 1 或 2 个迷宫内格子 `[row, col]`。

- 内部：对每格 `(r, c)`，若 `r+1 < size` 且 `!canMove((r,c),(r+1,c))` → `{x: c+0.5, z: r+1, along:'x', cells:[[r,c],[r+1,c]]}`；若 `c+1 < size` 且 `!canMove((r,c),(r,c+1))` → `{x: c+1, z: r+0.5, along:'z', cells:[[r,c],[r,c+1]]}`。
- 外边界：北边 `z=0` 每列一段，跳过 `c=0`（入口上沿）；西边 `x=0` 每行一段，跳过 `r=0`（入口左沿）；南边 `z=size` 跳过 `c=size-1`；东边 `x=size` 跳过 `r=size-1`。外边界共 `4*size - 4` 段。

- [ ] **Step 1: 写失败测试**

追加到 `tests/maze-3d-core.test.mjs`：

- 从 `maze.html` 截取 2D 的移动函数：`extractBlock(html, '\n        function canMove(fromRow')`、`'\n        function findNextIntersection('`、`'\n        function isIntersection('`。标记以换行符开头、后接恰好 8 个空格，锚定顶层函数：`findPath` 内部的同名 `canMove`（maze.html:1113，12 空格缩进）在顶层版本（maze.html:1269）之前，不带换行的 8 空格标记会作为子串先命中内部版本，在 vm 中调用报 `ReferenceError: height is not defined`。在 vm 上下文里预置 `currentMaze`、`currentConnections`、`currentSize` 求值。
- `test('extractBlock picks top-level canMove')`：截取结果匹配 `/currentConnections/`，且不匹配 `/\bheight\b/`（内部版本依赖 `findPath` 的局部变量 `height`）。
- `test('findNextIntersection matches 2D')`：seeds `[1, 42, 12345]` × sizes `[10, 15, 20]`，对每格每方向比较 2D 结果与 `findNextIntersection(connections, {row, col}, dir)`（2D 的 `null` 对 `null`，否则 `{row, col}` 深度相等）。
- `test('canMove: boundary and exits')`：`canMove(c, {row:0,col:0}, {row:-1,col:0}) === false`、`{row:0,col:-1}` 为 false；出口向下 / 向右越界为 false；非相邻（相距 2 或对角）为 false。
- `test('canMove requires both sides')`：手工构造 2×2 `connections`，`[0][0].right = true` 但 `[0][1].left = false` → `false`。
- `test('findPath from reachable positions')`：seeds `[1, 42, 12345]` × sizes `[10, 15, 20]`，从 `{row:0,col:0}` 出发，按 BFS 顺序反复调用 `findNextIntersection` 收集最多 30 个可达位置；对每个位置 `p = findPath(c, p, {row:size-1,col:size-1})`：`p.length > 0`、`p[0]` 等于起点、末格等于 `[size-1, size-1]`、相邻两格 `canMove` 为真。必须包含 seed=1、size=10 时的 `(3,6)`（`assert.ok(reached.some(…))`）。
- `test('findPath unreachable returns []')`：全 `false` 的 3×3 `connections`，`findPath(c, {row:0,col:0}, {row:2,col:2})` 深度等于 `[]`。
