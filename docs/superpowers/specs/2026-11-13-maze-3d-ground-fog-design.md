# 3D 迷宫外围地面与柔和迷雾设计

## 意图

承接「3D 迷宫连续移动与自由视角」（PR #15）。用户对那次改动的要求之一是「怎么让视觉效果更好怎么来」。查看 PR #15 的截图后发现两处明显的视觉问题：

1. **迷宫外面是空的**：迷宫只有格子地板，外面什么也没有。斜视角下（尤其小人在起点角上时）画面约一半是空天空，迷宫像悬浮在半空。
2. **迷雾外的地板是大片纯黑**：视野外格子统一着色 `0x333333`，在花园、积木等明亮主题下是一大块生硬的黑色。

本次只改视觉，不改操作、碰撞、迷宫生成、迷雾判定。

## 目标

- **外围地面**：迷宫四周加一大片与主题配套的地面，从迷宫边缘向外延伸到地平线：
  - 花园：草地（深浅不一的绿色草叶纹理）。
  - 砖墙：浅色石板广场（方形石板拼缝）。
  - 积木：大块积木底板（浅色带规则凸点，颜色与迷宫内地板区分开）。
  - 城堡：泥土地（棕灰色、带碎石点）。
- 外围地面略低于迷宫地板（低 0.02），视觉上迷宫地板是「铺在地面上的路」，不出现 z-fighting。
- **地平线渐隐**：两种视角都启用距离雾，远处的外围地面逐渐融入 `fogColor`，没有生硬的地面边缘。跟随视角的雾起止距离按相机距离与迷宫尺寸计算，保证迷宫本身完全不受雾影响；第一人称沿用现有迷雾半径对应的雾距离。
- **天空按世界方向着色**：现有天空是铺满屏幕的竖直渐变（屏幕底端才是 `sky.bottom`），而地平线在屏幕上的位置随俯角变化（跟随 15° 俯角时在屏幕上方约 21% 处，第一人称水平视线时在屏幕中部），地面雾色与紧邻的天空必然有色差。改为按视线的世界仰角着色：仰角 ≤ 0（地平线及以下）恒为 `fogColor`，仰角 0 → 90° 从 `sky.bottom`（= `fogColor`，四个主题现已相等）渐变到 `sky.top`。这样无论视角、俯角、窗口比例，地平线两侧颜色都相同。
- **外围地面边缘不可见（硬约束）**：任何可达的相机状态下，外围地面的所有可见边缘点雾因子都为 1。`THREE.Fog` 按相机空间深度（非欧氏距离）计算，宽屏窗口侧边的点深度远小于欧氏距离，所以地面尺寸必须按视锥计算，不能用固定外扩格数。
- **柔和迷雾格**：视野外格子不再是纯黑，改为每个主题自带的「雾地板色」`fogFloor`（主题地面色调的中暗色，例如花园用灰绿、城堡用深石灰）。视野边缘向外一圈（Chebyshev 距离 N+1）用普通地板色与雾地板色的中间色过渡，边界不再是一刀切。
  - 明确接受的视觉效果：过渡按整格着色，会形成「普通 → 中间色 → 雾地板」两道整齐的格状台阶，不是连续渐隐。这与迷雾按格判定、墙按格隐藏的格子风格一致，且不需要改着色器。连续渐隐（格内插值或多圈平滑权重）不在本次范围。
- 起点 / 终点 / 道路格语义不变；雾地板色与普通地板、起点、终点、道路色之间的 RGB 欧氏距离都 ≥ 60（沿用现有颜色可分辨验收）。过渡色只用在视野外第一圈，不参与该检查。
- 主题切换时外围地面纹理、雾地板色、雾色一起切换；纹理按主题缓存并释放旧主题的规则不变。

## 非目标

- 不加树木、石头、云朵等装饰物（以后可以再做）。
- 不改墙在迷雾外隐藏的规则。
- 不改操作、相机、碰撞、小地图。

## 反目标

- 开局跟随视角下画面仍有大片空天空、迷宫像悬浮。
- 外围地面能看到明显的边缘或与迷宫地板闪烁重叠。
- 迷宫内的格子被距离雾染色而看不清（跟随视角）。
- 帧率比改动前明显下降（同一性能检查平均帧时间增加超过 30%）。

## 方案

- `themes.js`：每个主题新增 `ground`（外围地面着色）与 `fogFloor`；新增 `paintGround(id, ctx, size)`，与现有绘制函数同样使用固定种子伪随机数，结果确定。
- `game-logic.js`：`floorKind` 增加 `'fogEdge'`（视野外第一圈）；`isInFogView` 不变，新增 `fogRing(center, cell, radius)` 判断是否属于过渡圈。
- `main.js`：
  - 新增一块外围地面网格：`PlaneGeometry` 正方形，纹理 `RepeatWrapping`，每格重复一次；放在 y = −0.045。
    - **跟随相机**：每帧把地面中心放到相机水平位置取整后的格点（`round(camera.x)`、`round(camera.z)`）。按整格移动，纹理图案在世界中保持不动；地面任一边缘点到相机的水平距离 ≥ 半边长 − 1。
    - **半边长** `E = groundHalfExtent(fogFarMax, fovDeg, aspect) = ceil(fogFarMax × sqrt(1 + tan²(fov/2) × (1 + aspect²))) + 2`。依据：视锥内任一点与视线方向夹角 ≤ θmax，`tan²θmax = tan²(fov/2) × (1 + aspect²)`（视锥对角），深度 ≥ 欧氏距离 × cosθmax ≥ 水平距离 × cosθmax，所以边缘点深度 ≥ fogFarMax，雾因子为 1。
    - `fogFarMax` 取所有可达状态的雾终点上界：跟随视角为 `followDistMax + 迷宫对角线 + 25`，其中 `followDistMax = hypot(followOffset(10)) × ZOOM_MAX`（`followOffset` 把半径封顶在 10，迷雾关闭时也按 10 算）；第一人称为 `max(25.5, size × 1.5)`；两者取大。20×20 时约 73.7。
    - 迷宫尺寸变化、窗口 `resize`（aspect 变化）时按新 `E` 更新地面缩放与纹理 `repeat`，不需要每帧重算。
    - 不变量：`fogFarMax < camera.far`（200）。地面超出远裁剪面被裁掉的部分深度 > 雾终点，已完全雾化，不会露出裁剪边。`groundHalfExtent` 放在 `game-logic.js`，为纯函数。
  - 天空：`makeSkyTexture` 改为等距柱状（equirectangular）贴图，`mapping = THREE.EquirectangularReflectionMapping`，仍赋给 `scene.background`（vendor 的 three r187 支持，背景按视线世界方向采样）。贴图上半部（仰角 90° → 0°）从 `sky.top` 渐变到 `sky.bottom`，下半部（仰角 < 0）纯 `fogColor`。天空贴图数量不变（仍是 1 张）。`renderer` 未开启色调映射，背景与雾色走同一 sRGB 输出，颜色一致。
  - 主题纹理从 4 张变为 5 张（新增外围地面）；调试对象的 `textureCount` 相应变为 5。
  - 雾：跟随视角也启用 `THREE.Fog`，`near = idealDistance() + 迷宫对角线`，`far = near + 25`；缩放、尺寸、迷雾开关变化时更新。`idealDistance` ≥ 实际相机距离（`cameraPullIn` 只会拉近），迷宫内任一点深度 ≤ 实际距离 + 对角线 < near，迷宫不受雾影响。第一人称不变。
  - 地板着色：`fog` 用主题 `fogFloor`，`fogEdge` 用 `floorBase` 与 `fogFloor` 各 50% 的混合色。
- 自动降画质时外围地面纹理同样把 `anisotropy` 降为 1。

## 测试

- 单元测试：
  - 四个主题都有 `ground`、`fogFloor`，`paintGround` 用记录调用的假上下文跑两次结果相同。
  - `fogFloor` 与 `floorBase`、起点、终点、道路色的距离都 ≥ 60（四个主题逐一检查）。
  - `floorKind` / `fogRing`：距离 N 为普通、N+1 为过渡、N+2 为雾；道路优先级不变。
  - `groundHalfExtent`：aspect 1 / 3 / 4 下，用视锥四个角方向的射线验证半边长处地面点的深度 ≥ fogFarMax；三种迷宫尺寸的 `fogFarMax` < 200。
- 浏览器验收（扩展现有脚本，其余检查保持通过）：
  1. 开局跟随视角截图：画面下半部分（地平线以下）采样点中，天空色占比 ≤ 10%（改动前记录基线作对比）。
  2. 四个主题切换后外围地面纹理随之变化，`textureCount` 恒为 5，反复切换 20 次不增长。
  3. 跟随视角下迷宫内格子颜色不受距离雾影响（采样迷宫远角格中心，与不开雾时的颜色差异 ≤ 8）。
  4. 迷雾格颜色语义检查沿用并通过；视野外第一圈为过渡色。
  5. 性能：与改动前同条件比较，平均帧时间不超过 1.3 倍。
  6. 四个主题各保存一张跟随视角截图到 `<repo>/.xdev/<run-id>/screenshots/` 供用户查看。
  7. 地面边缘：20×20 迷宫、迷雾关闭、缩放 1.5、俯角 15°、视口 1500×500（3:1），小人分别放在四个角，yaw 取 0°/45°/…/315° 共 8 个。每个状态：
     - 用调试接口读出地面中心、半边长、相机矩阵与当前雾终点，计算地面四条边与视锥的所有交点，断言每个交点的相机空间深度 ≥ 雾终点。
     - 截图左右各 5% 宽的竖条中，地平线以下的像素与 `fogColor` 的 RGB 距离 ≤ 8（侧边远处只能是雾色，不能露出地面截断线）。
  8. 地平线无接缝：四个主题 × {跟随俯角 15°、40°，第一人称俯角 0°、+20°、−20°}，取地平线所在行（由相机参数算出）上下各 3 像素、远离迷宫的列，两侧像素 RGB 距离 ≤ 8；各保存一张截图供人工检查。
