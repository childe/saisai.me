# 电路实验室 · 第 8 章红绿灯三关 设计

## 意图

用户最初想做一个"会自己变化的红绿灯"，选了用电容加继电器实现。电容元件和第 8 章第 1 关（id 40「会存电的电容」）已经合并。这次在第 8 章接着加三关，一步步搭到自动切换的红绿灯，每关只多一个新想法：

1. 电容让继电器延时松开；
2. 继电器用自己的常闭触点给自己供电，配上电容就会慢慢地自己一亮一灭；
3. 常闭接红灯、常开接绿灯，就是红绿灯。

用户选了"三关一步步搭"，不做黄灯；第 ③ 关预先接好闪光电路。

## 目标 / 非目标 / 反目标

- 目标：第 8 章新增 3 关，id 41、42、43（实现时若 main 上这些 id 已被占用，顺延，并同步改测试）。
- 非目标：黄灯（三色）；改求解器、电容或继电器的行为；新元件。
- 反目标：
  - 不用继电器、直接拿电池点灯就能过第 ① 关。
  - 不接电容、让继电器像第 7 章「自制电铃」那样哒哒乱跳，就能过第 ②、③ 关。
  - 第 ③ 关预置的闪光电路被孩子改坏。

## 方案

只有一种合理做法：沿用现有关卡写法（`lib/tasks/ch8-capacitor.js` 里加关卡对象，判定写在 `check`，用 `task-kit.js` 的工具）。时间相关的判定靠 `progress` 跨帧累计，和第 36 关「自制电铃」数翻转次数同一个思路。

## 关卡

### ① id 41「延时关灯」

- 题目：「断开开关以后，让继电器多吸一会儿，灯晚一点再灭」。
- 元件栏：`{ battery: 1, switch: 1, relay: 1, capacitor: 1, lamp: 1 }`，空画板。
- 一种正确接法：电池 → 开关 → 线圈 → 电池；电容并在线圈两端；电池 → 继电器 com，no → 灯 → 电池。1 节电池时，断开开关后灯再亮约 5 秒（0.1F）/ 24 秒（0.5F）/ 48 秒（1F）。
- 判定：某一刻所有开关都断开、某盏灯亮着，并且这盏灯靠继电器点亮——用同样的电路、损坏和电容电压，把继电器全部当作释放再解一次（`solve(circuit, broken, { on: new Set(), caps: ws.caps.v })`），这盏灯不亮。
- 提示：开关合着、灯亮着时提示「灯亮了。断开开关，看灯能不能晚一点再灭」。

### ② id 42「自己闪的灯」

- 题目：「不用开关，让灯自己一亮一灭」。
- 元件栏：`{ battery: 1, relay: 1, resistor: 1, capacitor: 1, lamp: 1 }`，空画板。
- 一种正确接法：电池 → com，nc → 电阻 → 电容∥线圈 → 电池；灯接在 nc（或 no）和电池负极之间。实测 1 节电池、10Ω、0.5F：灭约 1.8 秒、亮约 4.3 秒。
- 判定：数"慢速切换"。`progress` 记上次的灯亮灭状态、上次计数时各电容的电压、已数到的次数。灯的亮灭状态（任一盏灯亮算亮）变了，且自上次计数以来某个电容电压变化 ≥ 0.1 V，就计一次；计到 4 次过关。没有电容或电容不在回路里时，继电器乱跳不计数。
- 提示：无。

### ③ id 43「红绿灯」

- 题目：「给闪光电路接上红灯和绿灯，让它们自己轮流亮」。
- 预置（`lockPreset: true`）：第 ② 关的闪光电路，参数 2 节电池、47Ω、0.5F，不带灯。
- 元件栏：`{ led: 2, resistor: 2 }`。孩子自己把两个 LED 的颜色设成红、绿，每个串一个电阻；常闭接红、常开接绿。
- 实测（每个 LED 串 100Ω）：红约 4 秒、绿约 10 秒，LED 电流约 10 mA，不烧坏。
- 判定：同第 ② 关的慢速切换计数，但状态是"只有红灯亮" / "只有绿灯亮"（红、绿指 LED 的 `color` 参数），两种状态之间切换才计数，计到 4 次过关。
- 关卡说明里写一句：绿灯比红灯亮得久，因为电容充电比放电快。

## 测试

- 每关：正确接法过关；按反目标列的作弊接法不过关（① 灯直接接电池；②③ 不接电容、继电器自激）；③ 红绿接反（常闭接绿）也算过——判定不规定哪个触点接哪个颜色，只看两色轮流。
