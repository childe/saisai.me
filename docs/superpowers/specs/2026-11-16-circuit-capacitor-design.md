# 电路实验室 · 电容元件和第 8 章第一关 设计

## 意图

用户想在电路实验室里做一个会自己变化的红绿灯，选了用电容加继电器来实现（演示页面里的方案 ①）。这次先做打底：加电容元件，再加一关简单的题，让孩子认识电容能存电、放电。红绿灯关卡留到以后。

现在的求解器（`circuit/lib/solve.js`）每次只算稳定状态，元件没有"上一刻"的记忆。电容的电压取决于之前充了多少电，所以求解要能按时间一步一步推进。这是这次改动的主体。

## 目标 / 非目标 / 反目标

- 目标：
  - 新元件"电容"，自由搭建模式和关卡里都能用。
  - 电容充电、放电随时间变化，画面上看得出电容里存了多少电。
  - 新增第 8 章「电容与定时」，先放一关（id 38）：断开开关后，灯靠电容再亮一会儿。
- 非目标：红绿灯、闪光器关卡；电容的正负极、耐压和击穿；电容烧坏；交流电。
- 反目标：
  - 电路里有电容时画板变灰显示"暂时无法计算"，或者灯一闪一闪。
  - 没有电容的电路行为有任何变化（现有关卡和测试全部照旧通过）。
  - 电路稳定以后还每帧重新求解、重新渲染。
  - 第 38 关不用电容也能过。

## 方案（电容怎么算）

- **A. 后向欧拉等效（已选）**：每一步把电容看成"电导 C/h 并联一个电流源 C/h·v₀"（v₀ 是上一步的电压，h 是步长），代进现有的节点分析一起解。解出来的电容两端电压就是这一步末的电压。步长多大都不会算炸。
- B. 把电容看成电压源，每帧按电流积分电压（显式欧拉）：写起来最省事，但电容小、电阻小时，帧间隔一长就来回振荡甚至发散。
- C. 不进求解器，按 RC 公式直接算电压曲线：只适用于单个电容配单个电阻，接法一变就不对。

演示页面里展示过方案、用户选了用电容实现；A/B/C 的取舍是实现上的选择，选 A。

## 电容元件 `capacitor`

- 显示名「电容」，两个端点 `a`、`b`，不分正负极。
- 参数 `farads`：0.1、0.5、1（单位法拉），默认 0.5。数值按游戏里的灯泡选：1 节电池充满后接 10 Ω 小灯泡，1 F 能让灯再亮约 8 秒，0.5 F 约 4 秒，0.1 F 约 0.8 秒。（真实电容这么大的叫超级电容，元件说明里可以这么写。）
- 不会损坏，没有故障类型。
- 读数（`result.parts[id]`）：`v` 是 a 对 b 的电压，`i` 是从 a 流进电容的电流，`p = v·i`。

## 电容状态和时间推进

- 工作区新增一份电容状态 `caps`，和继电器状态 `relays` 并列：`{ v: { 电容id: 电压 } }`，没有记录的电容电压为 0。新放的电容、`重来`、换关都从 0 开始。删掉的电容在下一次 settle 时清掉记录（同 `pruneRelays`）。撤销（history）不恢复电容电压，和继电器一样。
- `solve(circuit, broken, opts)` 新增 `opts.caps`（电压表）和 `opts.h`（步长，秒）。每个没坏的电容盖章：a、b 之间电导 `C/h`，再加从 b 经电容注入 a 的电流 `C/h · v₀`。
- **没有电池的分量也要解**：现在没有电池的分量直接全部记 0 V。改成：分量里有电池，或者有电压不为 0 的电容，就解；参考点优先用电池负极，没有电池就用第一个这类电容的 `b` 端。这样开关断开、电池被隔开以后，电容才能单独给灯放电。这是第 38 关的关键。
- **settle（每次编辑后）**：用很小的步长 `PHYS.CAP_H = 1e-3` 解，表示"这一瞬间"的样子，电容几乎就是一个电压为 v₀ 的电源；settle 不改电容状态。
- **tick（每帧）**：先照旧推进损坏和继电器。然后如果电路里有电容，用 `h = dt` 再解一次（dt 已在 `app.js` 限制在 0.1 秒以内），把解出的每个电容电压写回 `caps`，这次的解作为新的 `ws.result`。
- **静止检测**（实现方的决定）：所有电容的电流 |i| 都小于 `1e-6` A 时，不写回、不换 result，tick 返回原工作区对象，避免每帧重渲染。按电流判断和帧间隔无关：1 kΩ 配 1 F 这种很慢的充电（电流约 1.5 mA）也会照常推进，不会因为每帧变化小就被冻住，换成 120 Hz 屏幕也一样。
- **冲击电流**（实现方的决定）：没充电的电容一接上，近似短路，会有很大的冲击电流。照现有损坏规则处理，不为电容开例外：保险丝和电容直接串联会熔断，LED 和电容串联、不加电阻会烧坏，4 节电池直接接 1 F 电容可能闪一下短路报警。这和真实电路一致，也符合"没有电容的电路行为不变"。要补测试把这些行为固定下来。
- 解出来的继电器状态、损坏状态翻转时，沿用现有逻辑交给 settle；settle 用的是当前 `caps`。

## 画面

- 电容图形：两块平行极板（简笔风格）/ 一个电解电容罐子（卡通风格），旁边一根竖条显示存了多少电：填充比例 = |v| / 3 V，封顶 1。下方标容量（如 `0.5F`），写法同保险丝的额定电流。
- 元件栏、属性面板里能选 0.1 / 0.5 / 1 F，同电阻选阻值的做法。
- 导线上的电流小点按每帧的电流走，充放电时会越走越慢，不用另做。

## 第 8 章第 1 关（id 38）「会存电的电容」

- 章节表 `CHAPTERS` 加 `{ n: 8, name: '电容与定时' }`，新文件 `circuit/lib/tasks/ch8-capacitor.js`。
- 题目：「断开开关以后，让灯再亮一会儿」。
- 元件栏：电池 1、开关 1、小灯泡 1、电容 1。空画板开始。
- 判定：某一刻，某盏小灯泡是亮的（`lampLit`），同时每节电池的 |i| < 1 mA（电池没在供电）。满足就过关。这样直接拿电池点灯、不用电容是过不了的。
- 一种正确接法：电池 → 开关 → 灯；电容并在灯两端。合上开关，电容充电；断开开关，灯慢慢变暗熄灭。
- 提示（hint）：灯亮着但电池在供电时，提示「现在是电池在点灯。断开开关看看，灯还亮吗？」

## 测试

- 求解：电池 + 电阻给电容充电，按 tick 推进，1 个时间常数（RC）后电容电压约为 63%（误差 5% 内）；电容单独接灯放电，没有电池也能解出电流。
- 没有电容的电路：现有测试全部照旧通过。
- 静止检测：充满以后 tick 返回同一个对象；1 kΩ 配 1 F 在 dt = 8 ms 下也能充上电。
- 冲击电流：保险丝和电容串联会熔断，LED 和电容串联会烧坏。
- 第 38 关：正确接法断开开关后过关；只用电池点灯不过关；电容没接或接错不过关。
- 删掉电容后 `caps` 记录被清掉；`重来` 清零。
