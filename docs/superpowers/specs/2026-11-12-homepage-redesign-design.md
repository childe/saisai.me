# 首页改版设计：赛赛的工具箱

## 意图

现在的首页 `index.html` 长得像一个文件目录：每个工具是「📁 文件夹英文名 + 📄 一行文字链接」。用起来的人主要是赛赛——一年级小朋友，认字不多。用户原话：「不要是文字条目，而是一个略大一点的图片吧。其他的你看着办。」

所以首页要从「目录」变成「一屏大图卡片」：小朋友扫一眼看图就知道点哪个，不需要读文字。

## 目标

- 每个工具是一张大卡片，卡片的主体是一幅插图，插图占卡片面积的大半。
- 插图本身就能让人认出这个工具是干什么的（看图识物，不靠读字）。
- 工具名用大号字写在插图下方，作为辅助；可再加一行很短的说明（给大人看），字号明显更小。
- 整页好看、统一、有童趣，但不廉价花哨。
- 在 iPad / 手机 / 电脑上都好用，卡片大、好点。

## 非目标

- 不改任何子工具页面（拼音、英语听力等）的内容和样式。
- 不加「返回首页」之类对子页面的改动。
- 不引入构建步骤、框架、npm 依赖。
- 不做搜索、分类筛选、收藏、最近使用等功能。
- 不更新 README.md（我的判断：README 是给大人看的，本次只改首页）。

## 反目标（做到了也算失败）

- 看起来仍像列表或目录：一行行文字、文件夹图标、英文目录名。
- 插图看不出是什么，小朋友只能靠读字才能选。
- 依赖外部 CDN / Google Fonts / 外部图片：在国内网络下可能加载慢或失败，导致首页空白或字体闪烁。
- 点击区域小，小手点不准。

## 约束

- 纯静态单文件 `index.html`，GitHub Pages 部署（仓库有 `CNAME`）。
- 链接目标保持不变：

  | 工具 | 链接 | 插图要表达的东西（我的判断） |
  |---|---|---|
  | 学拼音 | `pinyin/index.html` | 带声调的拼音字母，例如 ā á ǎ à |
  | 英语听力 | `english-audio/index.html` | 耳机 / 声波 + ABC |
  | 解方程（一元一次方程） | `solve-equation/index.html` | 天平或「x = ?」算式 |
  | 坐标绘图器 | `x-y-line/coordinate-plotter.html` | 坐标轴 + 两个点 + 一条直线 |
  | 迷宫生成器 | `maze-gen/maze.html` | 迷宫图案，起点到终点 |
  | 跳一跳 | `tiao-yi-tiao/game.html` | 小人 + 两个方块 + 跳跃弧线 |

- 页面 `<title>` 保持「赛赛的工具箱」，`lang="zh-CN"`。
- 字体用系统字体栈（PingFang SC、Hiragino Sans GB、Microsoft YaHei 等），不加载网络字体。

## 已定的做法（我的判断，用户已授权「看着办」）

- **插图用内联 SVG**，直接写在 `index.html` 里，不用位图、不用外部文件。理由：零请求、任意尺寸清晰、风格统一、好维护。风格：扁平插画、圆角、粗细一致的描边或无描边、每张卡片一个主色。
- **布局**：卡片网格，桌面 3 列、平板 2–3 列、手机 2 列（窄于约 360px 时可 1 列）。六张卡片不分组，按上表顺序排列，学习类在前、游戏类在后。
- **卡片结构**：整张卡片是一个 `<a>`，点卡片任意位置都进入工具。上部是插图区（带该工具主色的浅色底），下部是大号工具名 + 一行小字说明。
- **页头**：大标题「赛赛的工具箱」，可配一个小装饰（例如工具箱或星星 SVG），不需要导航栏。
- **配色**：暖色浅底（奶油色/米白），每张卡片一个柔和主色，彼此区分明显；文字深色，对比度满足可读性。
- **交互**：悬停 / 按下时卡片轻微上浮或缩放，有过渡动画；尊重 `prefers-reduced-motion`。键盘可聚焦，焦点样式清晰可见。
- **只做浅色主题**，不做暗色模式。
- 无 JavaScript。
- 每个插图 SVG 带 `aria-hidden="true"`（卡片的可访问名称来自文字标题）。

- **卡片标题用短名**（表中第一列），原来的长名放进小字说明，例如「一元一次方程求解」「一年级上册」。
- **断点**：≥ 900px 3 列；360–899px 2 列；< 360px 1 列。

## 留给实现者

- 具体的颜色值、圆角、阴影、间距、字号。
- 每幅插图的具体构图与细节，只要满足「看图能认出工具」。
- 卡片说明文案（一行，短）。
- 页脚有没有、写什么（可以没有）。

## 验收

- 打开首页，六张卡片都以插图为主体展示，无文件夹/文件图标、无英文目录名。
- 六个链接都能打开对应工具页面（路径与上表一致）。
- 在 375px 宽和 1280px 宽下布局正常，无横向滚动。
- 页面不发出任何外部网络请求。
